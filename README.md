# Level Tag System (Geometry Dash Mod)

A [Geode](https://geode-sdk.org/) mod for Geometry Dash that introduces a persistent Tag & Filter system for levels.

## Features
- **Custom Tags:** Assign categories like "Memory", "Sync", "Nostalgic", and more to any level.
- **Level Info UI:** View assigned tags as visual badges on the `LevelInfoLayer`.
- **Search Filtering:** Filter the `LevelBrowserLayer` to only display levels containing your active tags.

## Building from Source

To build this mod, you will need the Geode CLI and SDK installed.

1. Clone this repository.
2. Open a terminal in the repository folder.
3. Run `geode build` to compile the mod for your current platform.
4. The compiled `.geode` file will be placed in your Geometry Dash `geode/mods` folder automatically.

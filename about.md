# Level Tag System

Take control of your Geometry Dash level library by categorizing levels with custom tags!

### Features
* **Tag Management:** Add descriptive tags (like *Memory*, *Gimmick*, *XL*, *Learny*) directly from the Level Info screen.
* **Visual Badges:** Instantly see a level's tags displayed as neat badges under the level name.
* **Browser Filtering:** Use the new "Tag Filter" button in the Level Browser to only show levels that match your selected tags.

*Built with standard Geode UI and saved data systems to ensure your tags persist across sessions.*
